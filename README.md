## ✨ Key Features

- ⚡ **Single Reel Downloader**: 1-click paste with instant HD preview, one-tap MP4 video download, and direct caption copying.
- 📚 **Multi-Reels Batch Mode**: Paste 1, 5, or 50 Instagram reel links at once. Automatic link parsing with live counter.
- 🛡️ **Safe Delay Queue**: Anti-throttling randomized delay mode to safely download bulk reels without browser rate-limits.
- 📝 **Matching .txt Captions**: Save individual .txt caption files for every downloaded reel for easy archiving.
- 🎨 **Modern Dark UI**: Fluid Glassmorphism design built for speed, responsiveness, and zero clutter.
- 🔄 **Built-in Auto-Updater**: Automatically checks and applies new feature updates seamlessly in the background.

## 🚀 Installation Guide

1. **Download**: Click [**Download InstaDown Setup (.exe)**](https://github.com/usman-flutter-dev/instadown-app/releases/latest).
2. **Install**: Run InstaDown-Setup-1.0.5.exe and follow the on-screen installer.
3. **Launch**: Open **InstaDown** from your Desktop shortcut or Start Menu and start extracting reels in HD!
